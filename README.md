# react-native-fuzzy-highlight

Fast, fuzzy-tolerant text highlighting for React Native search results

## Installation


```sh
npm install react-native-fuzzy-highlight
```


## Usage


```js
import { multiply } from 'react-native-fuzzy-highlight';

// ...

const result = multiply(3, 7);
```
